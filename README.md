# MGMT 342 — in-class exercise sets

Managing AI & Emerging Tech · Xavier University · Fall 2026 · Humphrey & Mathai

This repository holds the hands-on pages for the build sessions. Open the folder for the day's session and work down the page with us.

**You do not need a GitHub account to use this.** Read it right here in the browser.

## How to use these pages

Every prompt sits in its own grey box. Hover over the box and a **copy icon** appears in its top-right corner — click it, then paste into the tool. Do not retype prompts by hand.

Some prompts contain `[SQUARE BRACKETS]`. Replace those with things that are actually true about you before you send. If you leave the brackets in, you will get a paragraph about `[YOUR MAJOR]`.

## Sessions

Each build session gets its own folder — `session-2/`, `session-4/`, and so on — with the page inside it. Open the folder for the day and the page displays on its own.

Some sessions ask you to bring something with you. When they do, it is at the top of that session's page under **Bring these**, and it is worth reading before you walk in rather than at 4:00.

## This folder is also an agent

[`CLAUDE.md`](CLAUDE.md) is a map that lets an AI assistant navigate this repository for you — upload it alongside a session page and ask your question in plain language. It is the same *folder-is-the-agent* pattern as your course folder, and the thing you build yourself in Module 2.

It also tells the assistant not to spoil the exercises for you. Respect that and the sessions still work.
