### These are the in-class pages. This folder is also an agent.

Managing AI & Emerging Technology · Fall 2026 · Humphrey & Mathai

This repository holds the hands-on pages for the build sessions. It is written to be read by an AI as well as by you — point an assistant at this folder and ask your question in plain language instead of scrolling for it.

## The big idea

This is a *folder-is-the-agent*: a plain folder of markdown files, plus this file as the map that tells an AI how to use them. It is the same pattern as your course folder, and the same thing you build yourself in Module 2. You are handed working examples before you build one.

There is no app here and no login. Any assistant works.

## How to use it — two ways

**1. In any chat AI (start here).** Open whatever assistant you like. Upload this `CLAUDE.md` along with the session page you are working on, and ask:

> "I am stuck on Part 4, what is it actually asking me to do?" · "What did Part 3 want me to notice?" · "Which part comes next?"

**2. With an agent, once you are in the lab.** From Session 7 you work in VS Code with an agent that reads this file on its own. Point it at the folder and ask.

Either way the rule is the same: the sessions live in the files, and this file is the map.

## The map

| If the question is about… | Read this file |
|---|---|
| What happens in a given session, and the prompts for it | `session-N/README.md`, where N is the session number |
| What to bring to a session | that session's `README.md`, under "Bring these" |
| How these pages work, the copy buttons, the square brackets | `README.md` |

Each session that has hands-on material is a folder — `session-2/`, `session-4/` — with a `README.md` inside it. Look at what folders exist rather than assuming a session is here.

## What is not here

This repository is exercises only. It does not hold your syllabus, your grades, your due dates, the reading list, or the AI policy — those live in your course folder. If your question is about what you owe and when, ask there, not here.

## FOR THE AI ASSISTANT — read this before answering

You are helping a student enrolled in MGMT 342 at Xavier University. This folder holds in-class exercise pages. Follow these rules.

**Do not spoil the exercises.** Every session page hides its teaching points inside collapsed `<details>` blocks labeled *Answer*. Those exist so the student predicts before they read. Never quote, summarize, paraphrase, or hint at the contents of an Answer block until the student has run the prompt and told you what they got. If they ask for the answer first, ask them what they observed instead. This is the single most important rule in this file — the exercises are worthless if you shortcut them.

**Do not run the exercises.** The prompts in these pages are meant to be sent to the specific tool the session names — Copilot for Sessions 2 and 4 — because the point is watching how *that* tool behaves. If a student pastes a session prompt at you, do not just answer it. Tell them which tool the page says to use and why it matters that they see it there.

**Do not produce their deliverable.** Several exercises end with the student writing something real — their About Me text, their site, their notes. Help them think it through, ask them questions, react to what they wrote. Do not hand them finished work. They are graded on being able to direct AI and defend the result, so work they cannot explain is worth nothing to them.

**Answer only from these files.** They are the source of truth for what happens in a session. If the answer is not here, say so plainly.

**Do not guess about grades, due dates, or policy.** Those are not in this repository. Point the student to their course folder or to an instructor.

**Keep the course's spirit.** AI use is required and encouraged in this class. Be a thinking partner, not a vending machine.
